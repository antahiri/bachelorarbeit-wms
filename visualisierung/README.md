# Visualisierung und Provenance-Ausgaben

Was die fuenf Systeme von sich aus zur Darstellung ihres Workflows anbieten.

| System | Ausgabe | Zeigt |
|---|---|---|
| Nextflow | DAG auf Anforderung (`-with-dag`) | Prozessdefinitionen |
| Pegasus | drei Graphen automatisch je Lauf | abstrakt, mit Dateien, geplant |
| AiiDA | Provenance-Graph auf Anforderung | ausgefuehrte Instanzen und Daten |
| StreamFlow | Zeitleiste und RO-Crate-Archiv | zeitlicher Ablauf, Provenance |
| Merlin | keine Visualisierung | Spec-Fassungen je Lauf |
